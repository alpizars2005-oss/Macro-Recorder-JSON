# Automation profiles

Automation Studio saves its local workflow profiles in this folder by default.

A profile can contain screen coordinates, sampled button colors, timing values, a foreground-window rule, and a path to a personal macro. Personal `.json` profiles in this folder are ignored by Git so they are not uploaded to the public repository by accident.

Use profiles only with computers, accounts, applications, and workflows that you own or are explicitly authorized to automate. Press `F12` at any time to stop Automation Studio.
