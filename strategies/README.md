# Recorded strategy profiles

The Recorded Strategy runner stores local `.json` profiles in this folder when the project is run from source. Installed Windows builds use `%LOCALAPPDATA%\MacroRecorderJSON\strategies`.

Profiles may contain local macro paths, screen requirements, timing values, ability keys, and captured end-button coordinates and colors. Personal strategy JSON files are ignored by Git so they are not uploaded to the public repository by accident.

Use recorded strategies only on computers, accounts, applications, and workflows that you own or are explicitly authorized to automate. Keep the target window in front and press `F12` at any time to stop all playback and automatic key pulses.
